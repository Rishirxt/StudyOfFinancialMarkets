# Agent-Based Market Simulation

A configurable financial-market simulator with a price-time-priority limit order book, a FastAPI service, and a React dashboard. Prices and trades are generated by interacting agents; live exchange data is optional and is used only to seed a simulation's starting price.

## Features

- **Agent-based market:** fundamentalists, trend-followers, noise traders, leveraged traders, and an optional human trader interact through a limit order book. The engine records fills, price history, round metrics, agent wealth, and OHLCV candles.
- **Reproducible experiments:** seeded simulations, batch runs, parameter sweeps, and a phase diagram of trend-follower count versus reaction sensitivity.
- **Hysteresis study:** ramp reaction sensitivity up and down, compare pre- and post-shock price and volatility windows, and summarize results across seeds.
- **Live dashboard:** stream simulations over WebSocket with price charts, order-book depth, agent wealth, trade/event logs, and pause/resume/stop controls.
- **Market and risk experiments:** optional strategy switching (herding), leverage and margin calls, and circuit-breaker halts. A human trader can submit orders during a live run.
- **Optional market reference:** the live dashboard can use generated prices or fetch a recent close for a supported Nifty 50 symbol from BSE. The simulation itself does not require exchange data.
- **Historical validation tools:** compare simulated return statistics with the bundled S&P 500 close series in `data/reference_sp500.csv`.

## Requirements

- Python 3.11 or newer
- Node.js and npm (for the React dashboard)

## Setup

From the repository root, create and activate a Python environment, then install the dependencies:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Install Python and frontend dependencies:

```bash
pip install -r requirements.txt
cd frontend
npm install
```

## Run the project

Start the API from the repository root:

```bash
uvicorn backend.api:app --reload --port 8000
```

In another terminal, start the frontend:

```bash
cd frontend
npm run dev
```

Open the local Vite URL printed by the frontend command (usually `http://localhost:5173`). The API health check is available at `http://localhost:8000/api/health` and interactive API documentation at `http://localhost:8000/docs`.

To run the command-line simulation demo instead:

```bash
python main.py
```

## Dashboard areas

- **Live market:** configure the agent population, sensitivity, simulation length, data source, and optional leverage, circuit breaker, herding, or human trading. Inspect streamed market activity and metrics.
- **Leverage:** compare a run with leveraged traders and margin-call liquidations.
- **Circuit breaker:** run an experiment with configurable drawdown trigger, lookback, and halt duration.
- **Phase diagram:** sweep trend-follower populations and reaction sensitivities across seeds and visualize volatility.
- **Hysteresis:** evaluate whether price or volatility remains shifted after a sensitivity shock is reversed; results include per-seed outcomes and a summary.
- **Batch simulation:** run a synchronous simulation and view its candles and order-book summary.
- **Herding:** study strategy switching based on recent relative profitability.

## API overview

The FastAPI application is defined in `backend/api.py`.

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/health` | Service health |
| `GET` | `/api/market-data/nifty50` | Supported BSE/Nifty 50 symbols |
| `POST` | `/api/simulate` | Run a simulation and return prices, candles, and order-book state |
| `POST` | `/api/phase-diagram` | Run a parameter sweep and return a volatility matrix |
| `POST` | `/api/hysteresis` | Run a multi-seed hysteresis experiment |
| `POST` | `/api/simulate-live` | Run a live-style simulation synchronously |
| `POST` | `/api/simulate-leverage` | Run a leverage and margin-call experiment |
| `POST` | `/api/simulate-circuit-breaker` | Run a circuit-breaker experiment |
| `POST` | `/api/agent-wealth` | Return agent wealth trajectories |
| `POST` | `/api/herding-experiment` | Run a strategy-switching experiment |
| `WebSocket` | `/ws/simulate-live` | Stream a simulation round by round; accepts live controls and human orders |

Request schemas and parameter bounds are documented in `/docs`.

## Core design

- `core/order_book.py` matches limit orders using price-time priority and returns trades at the resting order's price.
- `core/simulation.py` coordinates agents, matching, fills, round records, and seeded runs.
- `core/agent_factory.py` builds populations from `AgentSpec` configuration.
- `core/phase_diagram.py` and `core/hysteresis.py` implement the parameter sweep and ramp experiments.
- `core/herding.py`, `core/circuit_breaker.py`, and `core/human_trading.py` implement optional market mechanisms.
- `core/candles.py` aggregates trades into OHLCV candles; `core/validation.py` provides stylized-fact metrics.
- `agents/` contains the trader implementations, including leveraged and human traders.
- `frontend/src/components/` contains dashboard panels and charts.

## Tests

Run the test suite from the repository root:

```bash
python -m pytest
```

The tests cover agents, order-book matching, simulation bookkeeping, validation, phase diagrams, hysteresis, and advanced features.

## Known limitation

The bundled S&P 500 data shows fat tails and volatility clustering. Earlier validation runs found that the default fixed-composition simulated market can produce fat tails but does not reliably reproduce volatility clustering. Strategy switching is implemented as an optional herding mechanism and can be explored in the dashboard; its presence should not be taken as a claim that the stylized fact is reproduced under every configuration.
